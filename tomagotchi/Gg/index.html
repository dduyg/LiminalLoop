magic sketchpad

What is this?

Magic Sketchpad is an interactive, machine-learning-powered drawing experience that explores human-AI creative collaboration. Built using Magenta.js and the SketchRNN model, the application invites users to sketch simple doodles and watches as an artificial intelligence attempts to complete the drawing based on a selected category.

Trained on millions of doodles from Google's extensive Quick, Draw! dataset, the system recognizes patterns in real time to predict and extend your artwork. Users can select different object categories and layer multiple drawings onto a single canvas, creating a dynamic dialogue between human intuition and machine intelligence.
